# Generated character data

This directory contains the online character catalog generated from `library/seed/`.

The Android app should fetch `characters.json` from this directory and refresh it in the background. Character portraits are stored in `/images/<ID>.webp`.

Source format:
- `library/seed/01_Wuthering_Waves.xlsx` → IDs `1.x`
- `library/seed/02_Genshin_Impact.xlsx` → IDs `2.x`
- `library/seed/03_Honkai_Star_Rail.xlsx` → IDs `3.x`
- `library/seed/04_Arknights_Endfield.xlsx` → IDs `4.x`
- `library/seed/05_Zenless_Zone_Zero.xlsx` → IDs `5.x`
