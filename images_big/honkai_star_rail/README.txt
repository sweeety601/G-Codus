G-Codus — Honkai: Star Rail portrait folder

Place local character portraits here as WebP files:
images_big/honkai_star_rail/<slug>.webp

Recommended slugs use lowercase Latin characters and hyphens:
acheron.webp
pearl.webp
evanescia.webp
mortenax-blade.webp
march-7th.webp
march-7th-the-hunt.webp
dan-heng-imbibitor-lunae.webp
dan-heng-permansor-terrae.webp
topaz-and-numby.webp
silver-wolf-lv-999.webp

The app checks local portraits first. A missing local portrait can use the online Prydwen fallback until a local file is supplied.
