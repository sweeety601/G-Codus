# G-Codus Admin

Отдельное Android-приложение для администрирования базы G-Codus.

## Возможности
- Добавление и редактирование персонажей.
- Автоматическая выдача и закрепление ID вида `1.55`.
- Портрет из JPG/JPEG/PNG/WEBP с автоматическим преобразованием в WEBP и сохранением в `images/<ID>.webp`.
- Редактирование общей базы с поиском по имени и ID.
- Редактирование подтверждённых и неподтверждённых баннеров.
- Выбор персонажей по карточкам с поиском; в поле 4★ доступны только персонажи редкости 4.
- Даты выбираются календарём и сохраняются как `YYYY-MM-DD`.
- Все изменения отправляются непосредственно в `sweeety601/G-Codus`.

## Доступ GitHub
При первом запуске нужен Fine-grained Personal Access Token с доступом к репозиторию и разрешением **Contents: Read and write**. Токен хранится в Android Keystore.

## Сборка
```
./gradlew :admin:assembleDebug
```

APK:
`admin/build/outputs/apk/debug/admin-debug.apk`
